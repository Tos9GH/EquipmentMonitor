# EquipmentMonitor

Консольное Java-приложение для учёта оборудования и контроля его технического состояния.

## Описание проекта

EquipmentMonitor позволяет регистрировать оборудование, отслеживать его основные технические параметры, выявлять отклонения от установленных норм и сохранять историю проверок.

Проект разработан в учебных целях для практического применения Java и принципов объектно-ориентированного программирования.

## Возможности

- Добавление нового оборудования с проверкой уникальности ID.
- Просмотр списка зарегистрированного оборудования.
- Поиск оборудования по ID.
- Проверка технических параметров.
- Определение общего состояния оборудования.
- Просмотр оборудования с выявленными отклонениями.
- Ведение истории проверок с датой и временем.
- Сохранение данных в текстовые файлы.
- Загрузка данных при повторном запуске.
- Проверка корректности загружаемых данных.

## Контролируемые параметры

Приложение контролирует три технических параметра оборудования:

- **Температура:** от 0 до 80 °C.
- **Напряжение:** от 210 до 230 В.
- **Ток:** от 0 до 20 А.

Если хотя бы один параметр выходит за допустимые пределы, оборудованию присваивается статус `WARNING`. В противном случае статус — `NORMAL`.

src/

### Основные компоненты

- **Main** — взаимодействие с пользователем и управление меню приложения.
- **model** — модели оборудования, статусов и записей истории проверок.
- **service** — логика работы с оборудованием, выполнения проверок и управления историей.
- **data** — файлы для хранения информации об оборудовании и истории проверок.

## Запуск приложения

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/Tos9GH/EquipmentMonitor.git
   ```

2. Открыть проект в IntelliJ IDEA.
3. Убедиться, что используется JDK 21.
4. Запустить `Main.java`.

## Хранение данных

Приложение использует два текстовых файла:

- `equipment.txt` — информация о зарегистрированном оборудовании.
- `history.txt` — история выполненных проверок.

Данные сохраняются и загружаются с помощью стандартных средств Java для работы с файлами.
